Algorithm Theory

Viva-ready explanations with complexity analysis

DFS O(V+E)

Depth-First Search

DFS explores as far as possible along each branch before backtracking. It uses a stack (or recursion call stack) to track the path. In maze solving, DFS dives deep into corridors before trying alternatives.

Time
O(V + E)
Space
O(V) — stack depth
✓ Pros
  • Low memory usage
  • Fast if goal is deep
  • Simple to implement
✗ Cons
  • Not guaranteed shortest path
  • Can get trapped in deep branches
Real-world: Topological sort, cycle detection, web crawlers, game tree exploration.
BFS O(V+E)

Breadth-First Search

BFS explores all neighbors at the current depth before moving deeper. It uses a queue (FIFO) and is guaranteed to find the shortest path in an unweighted graph.

Time
O(V + E)
Space
O(V) — frontier queue
✓ Pros
  • Guarantees shortest path
  • Level-by-level exploration
  • Complete algorithm
✗ Cons
  • High memory usage (wide frontier)
  • Slower than A* with heuristics
Real-world: Social network shortest path, GPS navigation (unweighted), peer-to-peer networks.
A* O(E log V)

A* Search Algorithm

A* combines the cost to reach a node (g) and a heuristic estimate to the goal (h). The evaluation function f(n) = g(n) + h(n) guides exploration toward the goal efficiently. Uses Manhattan distance as heuristic in grids.

Formula
f(n) = g(n) + h(n)
Heuristic
h(n) = |dx| + |dy| Manhattan
Time
O(E log V)
Space
O(V)
✓ Pros
  • Optimal & complete
  • Faster than BFS with heuristic
  • Explores fewer nodes
✗ Cons
  • Heuristic design matters
  • More complex to implement
Real-world: Google Maps routing, video game AI pathfinding, robotics motion planning.
Generator O(V)

Recursive Backtracking

A DFS-based maze generation algorithm. Starting from a random cell, it randomly visits unvisited neighbors, carving paths. When stuck, it backtracks. This creates a perfect maze — exactly one path between any two cells.

Time
O(V) — each cell visited once
Space
O(V) — recursion stack
✓ Pros
  • Always generates solvable mazes
  • Creates long, winding corridors
  • Simple recursive implementation
✗ Cons
  • Deep recursion for large mazes
  • Biased toward certain patterns
Real-world: Procedural level generation in games, network topology design.
